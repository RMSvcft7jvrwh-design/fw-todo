# わたげちゃん ピクセルペット — 制作データ

## 内容

- `index.html` — オフラインで開ける動作確認画面。猫をマウス/指で掴んで動かせます。
- `style.css`, `app.js`, `frame-data.js` — 画面とアニメーションの実装。素材の差し替えが可能です。
- `assets/frames/` — 48コマ、すべて背景透過の個別PNG（256×320 px）。
- `assets/sheets/` — 動作ごとの横並びスプライトシート（10枚）、全コマを8列×6行にした統合シート（1枚）。
- `manifest.json` — 動作ごとのコマ数、各コマのパス、表示時間、シート上の位置を記した設定ファイル。
- `sprites_contact_sheet.png` — 確認用の一覧画像。**チェック柄は確認用画像のみ**で、PNGコマ自体は透明です。
- `source/original_reference_sheet.png` — 元の生成画像（装飾付き）を保管したもの。

## 使い方

1. ZIPを解凍します。
2. `index.html` をブラウザで開きます。ネット接続は不要です。
3. 猫を長押しして移動させると「つかまれ・液体I字」になり、離すと落下→着地します。画面内では自動で動作します。
4. 下の操作ボタンで、各動作を個別に切り替えて確認できます。

|---|---:|---|
| idle | 4 | おすわり・瞬き |

## 技術仕様

- 個別のコマは各 256×320 px、RGBA（透過あり）。元画像から無拡大で切り出し、下辺から18 pxの基準位置に揃えています。
- `assets/sheets/all_48_8x6.png` は2048×1920 px、8列×6行の横読みです。
- `manifest.json` 内の `atlasIndex` が統合シート内の0始まりのコマ番号です。
- 実装側の再生時間は `durationMs` を参照。睡眠の滞在時間は動作再生周期とは別に設定しています。
- ブラウザの`index.html`が読み込む画像は`assets/frames/`の個別コマです。
- 既存のChatGPTペット規格（v1/v2）とは別形式です。規格変換や公式登録まで保証するものではありません。

## 既知の制約

- もとの概念図には「51コマ」と表記されていますが、実際に猫が描かれていたのは48コマです。**walk が1コマ、groom が1コマ、stretch が1コマ不足**しています。架空のコマは追加していません。
- 元画の小さな猫のコマはポーズ間で若干デザインが揺れ、首輪が省略されている場合があります。輪郭や配色のリタッチはしていません。
- 掴まれ動作は生成イラストを切り出したものです。実猫の体に負荷をかけるような持ち方を推奨するものではありません。
- 本ファイルは初期データ＋プレビューです。ブラウザ動作を含む環境別の実機検証は別途必要です。
