# 和風依頼掲示板 UI素材（スプライトシート切り出し）

元画像はユーザー提供の `image(20261105-013853).png` （1448×1086 RGBA PNG）。
各パーツをPNGで切り出し、元のアルファ透過を維持しています。生成し直しはしていません。

## 設置先
`src/main/resources/static/assets/todos/list/themes/japanese-board/`

## 主な素材
- `board-base.png`：屋根・提灯・柱・和紙面が一体化した掲示板本体。**中央は透明ではありません。9スライス用の木枠ではなく、縦横比を維持する装飾背景**として扱ってください。
- `title-todo-list.png` / `title-quest-board.png`：見出し板。文字は画像に焼き込まれています。
- `notices/notice-01-...png` ～ `notice-08-...png`：依頼書カード8種。
- `pins/`：画鋲4種。
- `buttons/`：文字入りボタン7種と小アイコン7種。クリック操作は実際のHTML `<a>` / `<button>` に割り当て、アクセシブルネームを付けてください。
- `stamps/`：済・進行中・未着手・重要。**既存Todoのcompletedが真なら「済」を使用可能。進行中・未着手などは既存の状態データに対応する場合のみ使用**してください。
- `tapes/` と `decor/`：テープ・桜・装飾。

## 実装上の注意
- ユーザー最優先事項は**編集・削除をカード内で常時使えること**。各依頼書の文字は画像に焼き込まず、HTMLで描画してください。
- カード画像は装飾が異なるため、画像の安全領域と文字レイアウトを検証してください。
- 元画像の外装は横幅が狭い縦長の掲示板。6列テーブルの背景として無理に引き伸ばさず、カードGridを想定してください。
- 小さな画像パーツや斜めの紙はCSSで画像全体を伸縮させると模様も変形します。最初は同じカード種類でPCとスマホをテストしてください。
- 画像はスプライトシートの一部を切り出したため、一部に微小な半透明エッジが含まれます。
- `preview-contact-sheet.jpg` は参照用（アプリへコピー不要）。

## Codex 実装方針
まず見た目より先に、検索・並び替え・各Todoの編集/削除URL・テーマ設定（`data-board=japanese/plain`）・Thymeleafの値を壊さないこと。PCはカードGrid、スマホは1列で配置。カードが増えても配置座標をDBに保存せず CSS Grid を利用。
